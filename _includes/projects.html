Inkwell.md: Markdown Editor for VS Code

  • TypeScript · React · VS Code Extension API

A VS Code extension that replaces the plain markdown editor with a rich WYSIWYG editor in the style of Notion or Dropbox Paper. Features include live PlantUML and Mermaid diagrams with side-by-side source editing, slash commands, tables, collapsible sections, drag-and-drop linking of workspace files, and AI completion suggestions through GitHub Copilot.
